Admin panel untuk mengelola katalog produk, dibangun menggunakan **Laravel 11**. Dirancang dengan struktur kode yang rapi dan mengikuti best practice Laravel modern untuk kebutuhan manajemen produk skala bisnis.

---

## ✨ Fitur

- 🔐 Autentikasi & manajemen akses admin
- 📦 Manajemen produk (tambah, edit, hapus, lihat detail)
- 🗂️ Manajemen kategori produk
- 🔍 Pencarian & filter katalog
- 📊 Dashboard ringkasan data
- 🎨 Antarmuka admin yang bersih & responsif

---

## 🛠️ Teknologi

- **Framework:** Laravel 11
- **Bahasa:** PHP, JavaScript
- **Database:** MySQL
- **Template Engine:** Blade
- **Styling:** CSS
- **Dependency Manager:** Composer & NPM
